RENTAL CAB PRICING STRUCTURE

This document explains how rental cab package fares are structured on Elixway. It is intended to help the AI assistant explain pricing concepts to customers. It does not contain live fare figures, as actual pricing is generated dynamically by the backend fare calculation system.

PACKAGE-BASED PRICING

Rental cab bookings are generally priced using predefined packages that combine a set number of hours with an included kilometer allowance, such as a 4-hour or 8-hour package. The package price covers usage within both the included hours and included kilometers.

FARE COMPONENTS

A rental cab fare is generally composed of the following components:

- Base package price, determined by the selected duration and kilometer allowance, along with the vehicle category.
- Extra kilometer charges, applied if actual distance traveled exceeds the included kilometer allowance for the package.
- Extra hour charges, applied if the trip duration exceeds the included package hours.
- Night charges, if the booking starts or extends into designated night hours.
- Waiting charges, generally applicable only if the vehicle is required beyond the total package duration.

EXTRA USAGE CALCULATION

If a customer exceeds either the included kilometers or included hours for their selected package, additional charges are calculated automatically at the end of the trip based on actual excess usage, using per-kilometer and per-hour rates associated with the selected vehicle category and package type.

FACTORS INFLUENCING FARE

Key factors influencing the final rental fare include:

- Selected package duration and kilometer allowance.
- Vehicle category chosen.
- Actual distance and time used during the trip.
- Time of day, particularly regarding night charges.
- City-specific pricing variations based on local operational costs.

CHOOSING THE RIGHT PACKAGE

Customers are encouraged to select a package duration and kilometer allowance that reasonably matches their planned itinerary to avoid excess usage charges. For itineraries involving significant travel distance within a city, a longer package or higher kilometer allowance may offer better value than a shorter package with frequent extra kilometer charges.

ESTIMATED FARE DISPLAY

Before confirming a rental booking, customers are shown the package price along with the included hours and kilometers, and the applicable extra usage rates, allowing them to understand potential additional costs if their actual usage exceeds the package limits.

FINAL FARE VARIATIONS

The final rental fare may vary from the base package price if actual usage exceeds the included hours or kilometers. Any such variation is calculated automatically and reflected transparently in the final trip invoice.

CUSTOMER SUPPORT

For questions about rental package pricing or extra usage charges applied to a specific trip, customers should contact Elixway customer support with their booking ID for a detailed fare breakdown review.
